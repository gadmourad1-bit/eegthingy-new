EEGNet / ShallowConvNet papers: typically use BCI Competition IV-2a (9 subjects × 288 trials each ≈ 2,600 trials) and still report that classical CSP+LDA is competitive on small subsets.
Rule of thumb: deep nets start beating CSP+LDA around 500+ trials per subject or 15+ subjects pooled. Below that, they overfit and lose to shallow methods.
Riemannian methods: shine specifically in the low-data regime (50–200 trials) because covariance matrices are a strong, low-dimensional inductive bias — you're not learning features, you're using geometry.
So your hierarchy of options, ranked for your data scale:

Pooled CSP + recalibrated LDA — works with as few as 3–4 subjects × 1 session each.
Riemannian + alignment — works even better at the same data scale, no extra trials needed.
Deep learning — skip until you have 10+ subjects or 1000+ trials.
The Riemannian route is genuinely a free lunch here: same data, better cross-subject transfer, no extra collection burden. The only cost is adding pyriemann as a dependency (pip install pyriemann, ~one extra import).

1. Pooled CSP + per-subject LDA recalibration (easiest)

Fit CSP on pooled multi-subject data (it learns robust spatial filters).
Fit LDA once on pooled data → "base classifier."
For a new subject: keep CSP frozen, refit only the LDA on their 1 calibration session (or do partial_fit-style mean shift on class means).
Why it works: LDA is just class means + shared covariance, so it adapts cheaply with little data.
2. Riemannian + transfer (best accuracy, moderate effort)

Work in covariance-matrix space with pyriemann.
Use Riemannian Procrustes Analysis or Riemannian Alignment to map each subject's covariances into a common reference frame (recenter each subject's covariances around the identity).
Train one MDM or TangentSpace+LR on the aligned pool.
New subject: collect a few trials → compute their reference → align → predict.
This is the current SOTA for cross-subject MI and explicitly designed for your use case.
3. Deep learning (EEGNet / Shallow ConvNet) with fine-tuning

Pre-train on all subjects, freeze early layers, fine-tune last layer on the new subject's calibration data.
Needs a lot of base data (10+ subjects) and a GPU to be worth it.
